🤖 Groq AI Chatbot

A simple yet powerful AI chatbot built using Groq Large Language Models (LLMs) and Streamlit.
This project demonstrates how to integrate Groq’s ultra-fast inference with a clean, interactive chat UI.

🚀 Features



   💬 ChatGPT-style conversational interface

   🧠 Conversation memory using session state

   ⚡ Ultra-fast responses powered by Groq LLM

   🔄 Multiple model selection (LLaMA, Mixtral, Gemma)

   🗑 Clear chat functionality

   🎨 Clean and professional UI with sidebar

🛠️ Tech Stack



   python

   Streamlit – Frontend UI

   Groq API – Large Language Models

   python-dotenv – Secure API key management
